# Консультант по проектам (MVP)

Демо-приложение по ТЗ: анализ сайта компании -> генерация 5 AI-идей -> обсуждение в чат-табах -> финальная консультация.

## Запуск

```bash
npm install
npm run dev
```

Сервер поднимается на `http://localhost:3001`.

## Что реализовано

- Экран анализа URL с 5 шагами прогресса.
- API анализа `POST /api/analyze` с нормализацией URL.
- Генерация и перегенерация 5 идей:
  - `POST /api/ideas/generate`
  - `POST /api/ideas/regenerate`
- Чат с табами и опросом `single/multi/free`:
  - `POST /api/chat/start`
  - `POST /api/chat/message`
- Финальная консультация в требуемой структуре.
- Модальное окно настроек с сохранением API-ключа (demo) в `localStorage`.

## Ограничения текущего MVP

- Внешний поиск/соцсети сейчас представлены упрощенно (в контексте фиксируется как сигнал для ручной проверки).
- LLM-генерация в API реализована как шаблонный движок для быстрого запуска демо-потока.
- Состояние хранится в памяти процесса backend и сбрасывается при рестарте.

## Основные файлы

- `src/server.js` — backend API и бизнес-логика MVP.
- `public/index.html` — структура интерфейса.
- `public/styles.css` — стили, layout, адаптив.
- `public/app.js` — клиентская логика шагов, идей и чата.
